# 苍穹外卖前端

Vue 3 + Vite，一个项目提供商家端和用户端，所有数据来自 Spring Boot 接口，无本地假订单或假商品。

## 启动

要求 Node.js 22.12+（已在 Node 24 验证）。

```powershell
cd F:\sky_take_out\sky-admin
npm.cmd ci --cache F:\Codex\npm-cache
npm.cmd run dev
```

- 管理端：http://localhost:5173/#/admin/dashboard，使用数据库中已有管理员账号与密码。
- 用户端：http://localhost:5173/#/user/menu，输入固定的模拟微信 code；同一 code 对应同一用户，首次自动注册。当前后端并非真实微信 OAuth，请不要作为生产身份认证使用。
- 后端默认 http://localhost:8080。可复制 `.env.example` 为 `.env.local` 配置地址。开发代理转发 `/api` 与 `/uploads`，无需改变后端 CORS。
- 此次获准补充 `/user/category/list?type=1|2`。需要重启后端以加载新增 Controller；接口沿用 `/user/**` 用户鉴权。

## 功能

- 管理：工作台真实统计、营业开关、订单筛选分页与详情、接单/拒单/派送/完成、分类/员工/菜品/套餐增删改、启停、图片上传、菜品口味与套餐组成、营业额/订单/用户/销量统计。
- 用户：分类菜单、菜品口味选择、套餐加购、购物车增减清空、地址新增与列表、备注及下单、订单分页详情、取消、再来一单、模拟支付。
- 地址接口仅支持新增和列表，故页面不提供后端尚未实现的编辑/删除。
- 管理员与用户各自保存 Token，请求头使用 `token`。失效时清理对应登录状态；退出登录清除浏览器凭证。后端没有登出撤销接口。
- 支付状态：0 未支付、1 已支付、2 已退款、3 待退款。退款没有执行接口，页面展示实际状态。
- 模拟支付依赖后端 `sky.payment.mock-enabled=true`；默认关闭时显示后端错误。没有真实支付和真实退款能力。

## 构建与测试

```powershell
npm.cmd run build
npm.cmd test
npm.cmd run preview
```

构建产物位于 `dist/`。使用 Hash 路由，静态部署无需路由回退。生产环境需将 `/api/` 转发至后端并移除 `/api` 前缀，将 `/uploads/` 转发至后端的同名路径。示例见 `deploy/nginx.conf`。

测试使用实际 Vue 模板和接口客户端，在内存中模拟 HTTP 响应，覆盖双端页面、Token 隔离、参数编码、业务错误和失效会话。它不替代运行数据库和后端的端到端验收。

## 联调验收

启动后端并初始化已有管理员/分类/商品后：管理员登录 → 新增地址所需用户自行登录 → 用户选择商品与口味 → 加购 → 地址新增 → 下单 → 开启模拟支付后支付 → 管理员接单、派送、完成 → 用户查看状态。取消已支付订单显示待退款。运行期间可通过各页面刷新按钮同步另一端的变化。
