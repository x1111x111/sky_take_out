### 计算口径和限制

- 平均值为 elapsed 的算术平均。P95/P99 使用 nearest-rank，即排序后第 ceil(p×N) 个样本；与 JMeter 报表的插值算法可能有差异。
- 时长为最早 timeStamp 到最晚 timeStamp+elapsed；吞吐为样本数/该时长。round2 不足 1 秒，不能用来估计可持续容量。
- 错误率按 JTL success 标记计算。两份文件 HTTP 均为 200，但没有响应体或业务 code 断言记录，**不能证明业务全部成功**。
- 观测最大线程不等于服务器并发容量。环境资源、缓存冷热、数据库数据量、前后端版本与计时器条件不完整；不能将两轮吞吐差异解释成性能提升或退化。
- 不能据此确认多实例一致性、数据库事务回滚、Redis 故障恢复、P99 在真实部署中的表现。
